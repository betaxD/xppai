# xppAI AX 2012 R3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver `xppai-ax2012` as an independent npm package and CLI for Microsoft Dynamics AX 2012 R3 while preserving the AX 2009 product byte-for-byte and semantically unchanged.

**Architecture:** The new product lives exclusively in `packages/xppai-ax2012/`, duplicates only the small amount of required Node.js infrastructure, and never imports runtime modules or semantic rules from the root package. Its local runtime provides the CLI, identity-validated cache, append-only XPO revisions, registry-driven parser, and transactional installation; its knowledge assets live in one canonical `assets/` tree, with Papai and direct specialists routed through a validated manifest.

**Tech Stack:** Node.js >=18, CommonJS, built-in APIs (`node:test`, `fs`, `path`, `crypto`, `child_process`), independent npm lifecycle, Markdown/JSON skill contracts, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-08-xppai-ax2012-r3-architecture-draft.md` (reviewed architecture)

## Global Constraints

- Keep specifications, plans, technical documentation, source, tests, identifiers, diagnostics, and commit messages in English.
- Support Microsoft Dynamics AX 2012 R3 only. Do not provide AX 2009 or D365 implementation guidance; do not use Chain of Command or D365 extension-class patterns.
- Use package `xppai-ax2012`, executable `xppai-ax2012`, skill namespace `xppai-ax2012-*`, and primary orchestrator `xppai-ax2012-papai`.
- Preserve the AX 2009 product at the repository root. Do not modify root `package.json`, `package-lock.json`, `bin/`, `src/`, `assets/`, `test/`, `skills/`, `commands/`, or `agents/`.
- Do not convert the root to an npm workspace. Install, test, pack, and publish AX 2012 only from `packages/xppai-ax2012/`, which owns its lockfile.
- Do not import AX 2009 runtime modules or semantic rules and do not introduce a shared kernel in this release.
- Treat `packages/xppai-ax2012/assets/` as the only AX 2012 source tree. Do not create top-level sibling mirrors named `skills/`, `commands/`, or `agents/`.
- Enforce the approved AX 2009 baseline: `xppai@1.0.22`, 59 passing tests, 64 dry-run package entries, 24,918 packed bytes, 83,940 unpacked bytes, shasum `6ff17b2555ace689dcd88607c16b22c8e563ba1f`, 27 published assets, and aggregate asset hash `20513c173dc32a40ab5c4ab2fb03aaea248e432f387ef384d4e716f25387d4cc`.
- Use `%LOCALAPPDATA%/xppai-ax2012/config.json`, `%LOCALAPPDATA%/xppai-ax2012/cache/xpo/`, `<resolved-cache-dir>/xpo-session-auth.json`, `XPPAI_AX2012_CACHE_DIR`, and config key `ax2012XpoCacheDir`; precedence is `--cache-dir` -> user config -> environment -> default.
- Put `schemaVersion: 1`, `product: "Microsoft Dynamics AX"`, `baseline: "2012-R3"`, and `producer.package: "xppai-ax2012"` in every index, extract, and session-authorization record. Reject missing, foreign, incompatible, or newer metadata without mutation or implicit migration.
- Keep XPO history append-only by normalized source identity and original-byte hash, with an explicit active revision. Diff requires explicit base/head revisions and reports added, modified, and removed objects.
- Preserve original bytes, BOM/encoding, byte/character/line offsets, and exactly three completeness states: `complete`, `incomplete`, `indeterminate`. XPO alone never proves the effective top layer, model ownership, subscribers, xRef, or portable object IDs.
- Commit no real customer XPO and no generated customer analysis. Synthetic fixtures must cover class, table, form, query, service, security, and nested `SOURCE #...` sections.
- Retire only paths recorded by the previous AX 2012 ownership manifest, still under approved roots and in the AX 2012 namespace. AX 2009 and user-owned sentinels remain byte-identical.
- Keep every export, including Claude commands, below `--out`. Install and upgrade are staged, validated, reversible, and idempotent in copy and symlink modes.
- Permit production-ready guidance only for `supported` domains or `gated` domains whose prerequisites pass. Deferred/out-of-scope domains return only the capability matrix's preliminary or gap behavior.
- Limit Papai to three investigation cycles by default. Exhaustion returns `Unknown` and the next required evidence, never a positive conclusion.
- Follow section 19 in order: package boundary; CLI/cache/revisions/ownership; parser; core/intake/manifest/Papai; 12 references; 5 specialists; help/docs; verification; technical review; independent publication.

The script scans assets and docs for positive recommendations of D365 constructs, AX 2009 fallbacks, post-handler-only guidance, unqualified production-ready language in gated/deferred domains, missing uncertainty phrases in XPO/parser docs, missing financial-dimensions promotion, and missing regionalization evidence requirements. ```js
const fs = require('node:fs');
const path = require('node:path');

const PACKAGE_ROOT = path.resolve(__dirname, '..');
const assetRoot = path.join(PACKAGE_ROOT, 'assets');
const docsRoot = path.join(PACKAGE_ROOT, 'docs');
const prohibition = /\b(?:do not|never|must not|forbidden|unsupported|reject(?:s|ed)?|prohibit(?:s|ed)?)\b/i;
const recommendation = /\b(?:use|implement|create|prefer|apply|adopt|add|extend)\b.*\b(?:Chain of Command|D365 extension class|AX 2009(?: fallback| rule| pattern| implementation)?)\b/i;
const postHandlerOnly = /\b(?:use|implement|prefer)\b.*\bpost-handler\b.*\bonly\b/i;
const forbiddenXpp = [/\[ExtensionOf\s*\(/i, /\bnext\s+\w+\s*\(/i];
const productionQualifier = /\b(?:not|never|must not|only after|requires?|blocked|before|gate(?:d)?|evidence)\b/i;

function markdownFiles(root) {
  return fs.readdirSync(root, { withFileTypes: true }).flatMap(entry => {
    const absolute = path.join(root, entry.name);
    if (entry.isDirectory()) return markdownFiles(absolute);
    return entry.isFile() && entry.name.endsWith('.md') ? [absolute] : [];
  });
}

function findForbiddenGuidance(text) {
  const findings = [];
  for (const line of text.split(/\r?\n/)) {
    if ((recommendation.test(line) || postHandlerOnly.test(line)) && !prohibition.test(line)) {
      findings.push({ kind: 'prose', line });
    }
  }
  for (const match of text.matchAll(/```(?:xpp|x\+\+)\s*\r?\n([\s\S]*?)```/gi)) {
    for (const pattern of forbiddenXpp) {
      if (pattern.test(match[1])) findings.push({ kind: 'xpp', pattern: String(pattern) });
    }
  }
  return findings;
}

function requirePatterns(text, patterns, label) {
  for (const pattern of patterns) {
    if (!pattern.test(text)) throw new Error(`missing ${label}: ${pattern}`);
  }
}

function validateReviewContracts() {
  const manifest = JSON.parse(fs.readFileSync(path.join(assetRoot, 'references/manifest.json'), 'utf8'));
  const byId = new Map(manifest.references.map(ref => [ref.id, ref]));
  if (byId.get('business.financial-dimensions')?.status !== 'supported') {
    throw new Error('financial dimensions must be supported');
  }

  const regional = fs.readFileSync(path.join(assetRoot, 'references', byId.get('business.regionalization').path), 'utf8');
  requirePatterns(regional, [/country\/region/i, /model.*layer|layer.*model/i, /configuration key/i, /metadata/i], 'regionalization evidence');

  for (const ref of manifest.references.filter(ref => ref.status === 'gated' || ref.status === 'deferred')) {
    const text = fs.readFileSync(path.join(assetRoot, 'references', ref.path), 'utf8');
    const unqualified = text.split(/\r?\n/).filter(line => /production-ready/i.test(line) && !productionQualifier.test(line));
    if (unqualified.length) throw new Error(`unchecked production-ready claim in ${ref.id}: ${unqualified.join(' | ')}`);
  }

  const xpoDocs = fs.readFileSync(path.join(docsRoot, 'xpo-cache.md'), 'utf8');
  requirePatterns(xpoDocs, [/\bcomplete\b/i, /\bincomplete\b/i, /\bindeterminate\b/i, /\bUnknown\b/, /original byte/i], 'XPO uncertainty contract');
}

function main() {
  for (const root of [assetRoot, docsRoot]) {
    for (const file of markdownFiles(root)) {
      const findings = findForbiddenGuidance(fs.readFileSync(file, 'utf8'));
      if (findings.length) throw new Error(`forbidden guidance in ${file}: ${JSON.stringify(findings)}`);
    }
  }
  validateReviewContracts();
}

if (require.main === module) main();
module.exports = { findForbiddenGuidance, validateReviewContracts };
