# XppAI Report Templates

## Template Mapping

- `technical-report` -> `Scenario Analysis Report`
- `session-resume` -> `Results Report`
- `change-report` -> `Technical Change Report`

## Template: technical-report

```md
# Scenario Analysis Report
**Tuning Project:** <title>
**Date:** <date>
**Author(s):** <author>
**Phase:** Analysis

---

## 1. Identified Problem
<problem statement>

## 2. Root Cause Analysis
<root cause, evidence, and metrics>

## 3. Business Impact
<business framing>

## 4. Proposed Solutions
<solution table>

## 5. Risk × Benefit × Effort Matrix
<comparison table>

## 6. Recommendation
<recommended option and rationale>

## 7. Action Plan
<phases, owners, duration>

## 8. Next Steps
<checkbox list>
```
