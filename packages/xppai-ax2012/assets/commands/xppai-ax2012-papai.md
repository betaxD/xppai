# xppai-ax2012-papai

Launch `xppai-ax2012-papai` for ambiguous, mixed, or multi-domain Microsoft Dynamics AX 2012 R3 work.

Expected inputs: the goal and whatever evidence is already available. Missing nonblocking context remains `Unknown`; Papai asks one focused question only when the missing context blocks the next safe action. Stop and report a baseline conflict when evidence belongs to another product baseline.
